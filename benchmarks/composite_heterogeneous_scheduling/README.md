# 复合异构调度实验

该实验通过 Loom 执行固定的园区巡检 DAG：100 张图片依次经过预处理、YOLO 检测、风险判定，最后生成一次汇总，共 301 个动态节点。固定 DAG 只负责提供可重复负载，节点分配仍由 Loom 的生产调度器决定。

## 证据边界

- A/B/C 是同一台 Mac 上使用不同 CPU 配额的容器，只代表“受控模拟异构”。
- 校准使用固定到单一 Slave 的 Loom Run，从 Attempt 中读取 YOLO `inference_ms`；不是在宿主机旁路测速。
- 正式结果必须保留失败运行，不能只比较成功样本。
- DeepSeek 不参与计时区间，避免模型输出波动污染调度算法比较。

## 顺序

1. 启动 Compose 并注册、激活预处理和 YOLO 服务到三个 Slave。
2. 运行校准（每端预热 2 次、测量 10 次）。
3. 运行 3 图冒烟矩阵。
4. 使用 `--formal --repeats 3` 运行 100 图六组合矩阵。
5. 使用 `summarize.py` 汇总原始 JSON。

数据文件通过参数传入，不复制进 Git；正式运行应使用同一个 manifest 和 zip 摘要。具体命令和本次实测结果见最终实验报告。
